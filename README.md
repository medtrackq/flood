# ระดับน้ำคลอง กรุงเทพฯ

เว็บดูระดับน้ำในคลองกรุงเทพฯ แบบเรียลไทม์ จากจุดวัดราว 200 จุด ได้แนวคิดจาก [POPNIX Flood](https://flood.pop.in.th/) และใช้ข้อมูลจาก [open API](https://flood.pop.in.th/api/) ของเว็บนั้น

## หน้า "เช็กถนนน้ำท่วม ทั่วไทย" (`/roads/`)

เช็กถนนที่มีน้ำท่วมหรือน้ำขังทั่วประเทศก่อนออกเดินทาง

- สรุปจำนวนจุดที่ **ผ่านไม่ได้ / ผ่านได้** และจำนวนจังหวัด
- ค้นหาด้วยชื่อถนน อำเภอ หรือเลขทางหลวง, เลือกจังหวัด, แท็บแยกตามสถานะ
- แผนที่และรายการ เรียงจากจุดที่ผ่านไม่ได้ก่อน กดรายการเพื่อดูรายละเอียด (กม., สาเหตุ, เบอร์ติดต่อหมวดทางหลวง) และเปิดใน Google Maps
- ปุ่ม **ใกล้ฉัน** เรียงจากจุดที่ใกล้ที่สุด
- ข้อมูลหลักจาก [Longdo Traffic](https://traffic.longdo.com) (มูลนิธิ iTIC) ซึ่งรวมรายงานของกรมทางหลวงและผู้ใช้ เสริมด้วยเซ็นเซอร์น้ำบนถนนของ กทม. ที่มีน้ำ
- feed ของ Longdo ส่ง CORS มาด้วย หน้านี้จึงใช้งานได้แม้ deploy เป็นเว็บ static อย่างเดียว (แต่จะไม่มีข้อมูลเซ็นเซอร์ กทม.)

> **ก่อนเปิดใช้จริง** ควรติดต่อ Longdo / มูลนิธิ iTIC เพื่อขออนุญาตและยืนยันรูปแบบการให้เครดิต เพราะยังไม่พบเงื่อนไขการใช้ feed ที่เผยแพร่ไว้

## ฟีเจอร์ (หน้าหลัก: คลอง กทม.)

- **แถบสถานการณ์**: สรุปเป็นประโยคเดียวว่าน้ำกำลังขึ้น ลด หรือทรงตัว สีเปลี่ยนตามความรุนแรง พร้อมเวลาน้ำทะเลหนุนสูงสุดรอบถัดไป
- **ตัวเลขสรุป**: จำนวนจุดที่ถึงระดับวิกฤต, เกินระดับเฝ้าระวัง, น้ำขึ้น/ลงใน 1 ชั่วโมง, จุดวัดที่ส่งค่า กดการ์ดวิกฤต/เฝ้าระวังเพื่อแสดงเฉพาะจุดเหล่านั้นบนแผนที่
- **ใกล้คุณ (จอเรดาร์)**: ใช้ GPS หรือเลือกจุดบนแผนที่ แล้วแสดงจุดวัดคลองและจุดวัดน้ำบนถนนในรัศมี 3 กม. บนจอเรดาร์ตามทิศจริง พร้อมสรุปว่าน้ำรอบตัวกำลังขึ้น/ลด ถนนมีน้ำไหม และรายการ 5 จุดที่ใกล้ที่สุด ปุ่ม **กล้องใกล้ฉัน** เรียงกล้องในรัศมี 5 กม. จากใกล้ไปไกล (จำตำแหน่งล่าสุดไว้ในเครื่อง)
- **แผนที่** (Leaflet + OpenStreetMap): จุดวัดทุกจุดแสดงสีตามระดับ กรองตามระดับได้ กดที่จุดเพื่อดูระดับน้ำ แถบเทียบเกณฑ์ แนวโน้ม และกราฟ 6 ชั่วโมงล่าสุด ปุ่ม **จุดวัดใกล้ฉัน** ใช้ GPS หาจุดวัดที่ใกล้ที่สุด (ต้องเปิดผ่าน https)
- **น้ำขึ้นน้ำลงวันนี้**: ค่าคาดการณ์ระดับน้ำทะเลหนุน ไฮไลต์รอบถัดไป
- **จุดที่น่าห่วงที่สุด**: 8 จุดที่ระดับน้ำสูงเมื่อเทียบกับเกณฑ์วิกฤต กดเพื่อไปยังจุดนั้นบนแผนที่
- **กล้อง CCTV ถนน**: ภาพนิ่งล่าสุดจากกล้องราว 1,400 ตัว (กล้องจราจร กทม., สำนักการระบายน้ำ กทม., iTIC) ค้นหาด้วยชื่อถนน/แยก/สถานที่หรือปุ่มค้นหาด่วน กดเพื่อดูภาพใหญ่ แล้วใช้ ← → ดูกล้องถัดไป
- โหลดข้อมูลใหม่อัตโนมัติทุก 2 นาที, รองรับมือถือ, สลับโหมดสว่าง/มืดได้ (จำค่าไว้ในเครื่อง)

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
npm start            # หรือ node server.mjs
# เปิด http://localhost:8080  (เปลี่ยนพอร์ตด้วย PORT=3000 npm start)
```

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บ |
| `assets/css/style.css` | สไตล์ (light/dark) |
| `assets/js/app.js` | ดึงข้อมูล วาดแผนที่และสรุปภาพรวม |
| `assets/js/cctv.js` | ผนังภาพกล้อง CCTV และการค้นหา |
| `assets/js/near.js` | ส่วน "ใกล้คุณ" และจอเรดาร์ |
| `roads/index.html`, `assets/js/roads.js`, `assets/css/roads.css` | หน้าเช็กถนนน้ำท่วมทั่วไทย |
| `server.mjs` | serve ไฟล์ static และ proxy ข้อมูลจาก POPNIX พร้อม cache (ดูด้านล่าง) |
| `data/overview.json` | ข้อมูลตัวอย่าง ใช้เมื่อเชื่อมต่อข้อมูลสดไม่ได้ |

### ทำไมต้องมี server

| เส้นทางบน server นี้ | ดึงจาก POPNIX | cache |
| --- | --- | --- |
| `/api/overview` | `/api_overview.php` | 60 วินาที |
| `/api/roads` | `/api_roads.php` (น้ำท่วมถนนและอุโมงค์) | 60 วินาที |
| `/api/thai-roads` | `https://event.longdo.com/feed/json` (เหตุการณ์จราจรทั่วประเทศ) | 60 วินาที |
| `/api/cams` | `/cctv/cams.json`, `/cctv/dds.json`, `/itic/cams.json` รวมเป็นรายการเดียว | 60 วินาที |
| `/cam/<แหล่ง>/<id>.jpg` | ภาพจากกล้อง (เฉพาะกล้องที่อยู่ในรายการ) | 2 นาที, เก็บไว้ไม่เกิน 400 ภาพ |

API ของ POPNIX ไม่ได้ส่ง header CORS มา เบราว์เซอร์จึงเรียกตรงจากโดเมนอื่นไม่ได้ อีกทั้ง POPNIX จำกัดไว้ที่ 30 ครั้ง/นาที/IP และขอให้เว็บที่มีผู้ใช้มากดึงผ่าน server แล้ว cache ไว้ `server.mjs` จึงดึงข้อมูลให้และ cache ไว้ 60 วินาที ถ้าต้นทางล่มชั่วคราวจะตอบข้อมูลล่าสุดที่มีอยู่แทน

หน้าเว็บจะลองดึงข้อมูลตามลำดับดังนี้: `/api/overview` (server นี้) → POPNIX โดยตรง → `data/overview.json` (ถ้าใช้ข้อมูลตัวอย่าง หน้าเว็บจะแจ้งเตือน) ถ้า deploy เป็นเว็บ static อย่างเดียว (เช่น GitHub Pages) จะเห็นแค่ข้อมูลตัวอย่าง

## เงื่อนไขการใช้ข้อมูล

> **ข้อมูลกล้อง CCTV ไม่อยู่ใน Open API ของ POPNIX** เว็บนี้ใช้ไฟล์กล้องที่ POPNIX รวบรวมไว้ ซึ่งยังไม่มีเงื่อนไขอนุญาตให้ใช้ ควรติดต่อขออนุญาตจาก POPNIX ก่อนเปิดให้คนทั่วไปใช้ ถ้า POPNIX เปลี่ยนหรือปิดไฟล์เหล่านี้ ส่วนกล้องจะใช้งานไม่ได้ แต่ส่วนอื่นยังทำงานตามปกติ


ตาม[เงื่อนไขของ POPNIX Flood](https://flood.pop.in.th/api/):

- ต้องแสดงเครดิต "ข้อมูล: สำนักการระบายน้ำ กรุงเทพมหานคร ผ่าน POPNIX Flood (flood.pop.in.th)" ใกล้กับข้อมูล (มีอยู่ใน footer แล้ว)
- **ไม่ใช่ประกาศเตือนภัยทางการ** ห้ามนำไปแสดงเป็นประกาศเตือนภัย
- ระดับน้ำมีหน่วยเป็นเมตรเหนือระดับน้ำทะเลปานกลาง (ม.รทก.) ไม่ใช่ความลึก
